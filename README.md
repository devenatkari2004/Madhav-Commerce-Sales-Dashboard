# Madhav Commerce Sales Analysis (Power BI Dashboard)
## Project Objective
To analyze Madhav Commerce sales data and build an interactive Power BI dashboard that helps understand business performance, customer behavior, and key revenue drivers to support better decision-making

## Dataset Used:
- <a href="https://docs.google.com/spreadsheets/d/1N_Aa45UnkPmnwGqNr6oTzvUhb5TKlitM/edit?gid=1081836936#gid=1081836936">Dataset </a>

## Process
Cleaned and transformed the raw data using Power BI Power Query, ensuring it was properly structured for analysis. Handled missing values and maintained consistency across all fields to improve data quality. Created efficient data models by establishing relationships between different tables. Built calculated measures using DAX for key performance indicators such as total sales, profit, and average order value (AOV). Finally, designed an interactive dashboard using charts, slicers, and filters to enable dynamic and insightful data visualization.

## Project Insights
-Clothing category contributes the highest share (~63%) of total quantity sold

-Cash on Delivery (COD) is the most preferred payment mode (~44%)

-Maharashtra and Madhya Pradesh are top-performing states in terms of sales.

-A few customers (like top 5 buyers) contribute significantly to revenue.

-Printers and Bookcases generate the highest profit among sub-categories.

## Conclusion
To improve overall sales and profitability, Madhav Commerce should focus on high-performing states like Maharashtra and Madhya Pradesh, while expanding reach in underperforming regions. Since Clothing dominates demand, inventory and marketing should prioritize this category. Additionally, optimizing COD operations and promoting digital payments like UPI can improve efficiency. Targeting high-value customers with personalized offers can further boost revenue and customer retention.
